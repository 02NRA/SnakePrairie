# Demiplane Domicile
Current mod version: 1.0.0

For MC version: 1.21.1

## Contents
Adds Pocket Dimensions that only one player can access, through either a pocket dimension item made using echo shards, or a bauble containg a memory.
Memories are used up dreams, which are in turn restored nightmares refined out of soul sand.
This is the most complex/interconnected of the mods in this repo.
